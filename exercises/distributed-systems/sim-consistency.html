Consistency checker: FIFO, causal, sequential

Load an exam schedule or type your own. The checker tests the three data-centric models, shows a valid order when one exists, and tells you which single operation to remove. Put ? as a read value to see which values are allowed.

Schedule

One line per process: P0: W(x)1 R(y)0 …. Variables start at 0. Each written value must be unique on its variable. Time does not matter: only the order inside each line.

How the checker decides

Sequential. Find one interleaving of all operations that keeps the order of each process, where every read returns the last value written before it.

Causal. For each process P, order all writes plus P's own operations. The order must respect causality: program order, and "a write comes before every read that returns its value", closed transitively. Concurrent writes can appear in different orders for different processes.

FIFO (PRAM). For each process P, order all writes plus P's own operations. Only the order of writes of the same process must be kept. Writes of different processes can appear in any order.

Sequential ⇒ causal ⇒ FIFO. So if a schedule is not FIFO, it is not causal and not sequential.
