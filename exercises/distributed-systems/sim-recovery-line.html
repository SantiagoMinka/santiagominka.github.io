How to build the edges

Notation. ci,x is the x-th checkpoint of Pi; ci,0 is the initial state. Ii,x is the interval between ci,x−1 and ci,x.

Rollback-dependency graph. Edge ci,x → ci,x+1 on each process. For a message sent in Ii,x and received in Ij,y: edge ci,x → cj,y (the checkpoints that end the two intervals). Mark the failure states, then everything reachable. Each process rolls back to its last unmarked node.

Checkpoint-dependency graph. For the same message: edge from the checkpoint that starts the send interval (ci,x−1) to the checkpoint that ends the receive interval (cj,y). Start from the root set (last checkpoint of failed processes, current state of the others). If a root is reachable from another root, replace it with the previous checkpoint and repeat.
